# projekt2_gruppe_1_db
Projekt 2 gruppe 1 ønskesky applikation

**--Hvordan laves database--**
1. Gå til src package -> main -> resources -> databaseScript.sql
2. ctrl/cmd + a -> marker alt tekst
3. ctrl/cmd + c -> copy
4. Åben mySqlWorkbench
5. ctrl/cmp + v -> paste script ind i query
6. Gå tilbage til intelliJ IDEA
7. Klik på cylinder logo (database)
8. Klik på det lille plus -> datasource
9. Find MySQL (IKKE amazon aurora mysql)
10. Klik på MySQL for at vælge version ->
11. I User feltet indtast brugernavn som kan findes i application.properties
12. I password feltet indtast password som ligeledes findes i application.properties
13. I database felt -> klik og vent på den loader
14. Vælg projekt2_gruppe1_db
15. Tryk apply eller OK knap
